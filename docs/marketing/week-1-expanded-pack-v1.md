## Posting Window Suggestions (Starter)

- Primary slot: local evening (high attention window).
- Secondary slot: local midday (repost/derivative window).
- Story/short note slot: late morning or post-stream planning window.

## QA Before Publishing Each Asset

- First 2 seconds are visually strong.
- One clear CTA only.
- Link is present and tested.
- Caption first line is platform-specific.
- Backup asset ready before publish.
