## Pre-Send Checklist

- [ ] Recipient name verified
- [ ] Subject line adjusted per station
- [ ] Song link tested
- [ ] Viz preview link tested
- [ ] Premiere link tested
- [ ] One-line fit rationale customized
- [ ] Sheet row updated to `sent`

## Logging Rules

After each send, update the outreach sheet:

- `first_outreach_date`
- `first_outreach_status` = `sent`
- `song_link_sent` = `yes`
- `viz_preview_link_sent` = `yes`
- `premiere_invite_sent` = `yes`
- Short notes with any bounce/auto-reply info

## Follow-Up Timing

- Follow-up 1: 3 to 4 days after send, only if no reply
- Follow-up 2: 4 to 5 days later, only if still no reply
