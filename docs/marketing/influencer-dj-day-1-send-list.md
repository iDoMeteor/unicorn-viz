Owner: Studio Marketing
Status: active

## Purpose

Define the first outreach wave for influencers and DJs using highest-fit contacts and channels.

## Day 1 Goal

- Send 15 personalized outreach messages.
- Keep a balanced mix of creators, DJs, and editorial amplifiers.
- Match tone mode to channel and audience profile.

## Pre-Send Checklist

- [ ] Recipient name or team alias verified
- [ ] Channel-specific subject line selected
- [ ] Song link tested
- [ ] Viz preview link tested
- [ ] Premiere link tested
- [ ] CTA narrowed to one action
- [ ] Tracker row updated to `sent`

## Logging Rules

After each send, update the influencer/DJ sheet:

- `first_touch_date`
- `first_touch_status` = `sent`
- `asset_pack_sent` = `yes` (if sent)
- `track_link_sent` = `yes`
- `preview_link_sent` = `yes`
- `premiere_link_sent` = `yes`
- Short notes (reply type, redirect, or bounce)

## Follow-Up Timing

- Follow-up 1: 3 to 4 days after first send, if no response
- Follow-up 2: 4 to 5 days after follow-up 1, if still no response
