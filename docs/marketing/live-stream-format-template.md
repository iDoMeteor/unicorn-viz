# Live Stream Format Template

Owner: Studio Marketing
Status: active
Last updated: 2026-06-16

## Purpose

Reusable run-of-show template for 3-hour live streams plus a bonus song at the end.
This version is designed to keep the live event feeling like a chaptered performance rather than a loose playlist.

## Recommended Order

Your proposed order is already strong. The main improvement is to treat the opening as a short ramp and to keep the final section clearly framed as the closing chapter.

Recommended sequence:

1. 30s intro timer
2. Animated logo video
3. Intro warning card/video
4. Intro DJ UT music video
5. Set 1
6. Feature video - DJ UT remix or special
7. Set 2
8. DJ UT random video
9. Set 3
10. Dedication plaque
11. Outro credits and links
12. Bonus song / final after-credits tag

## What You May Be Leaving Out

These are the items I would add or consider depending on the platform and how polished you want the stream to feel:

- A short spoken welcome after the animated logo and before the warning card, if you want a more human opening.
- A simple chapter title card before each set so the stream feels intentionally segmented.
- A backup bumper or fallback clip in case a video fails to load.
- A short mid-stream CTA moment for follows, links, or support if you want to avoid only doing that at the end.
- A final replay note or "what happens next" card after the outro credits.

## Suggested Flow Notes

### 1. Intro Ramp

Use the timer and logo sequence to absorb buffer time and let people arrive.
Keep this short and repeatable.

### 2. Warning + Intro Video

The warning card should come before any strong visual or bass-heavy material.
That keeps the opening clear and prevents surprise.

### 3. Set Block Structure

If possible, make each set block feel distinct:

- Set 1 = arrival and lock-in
- Set 2 = momentum and feature turn
- Set 3 = peak and finish

### 4. Closing Block

The dedication plaque works best after the main final song and before credits.
That lets the stream close emotionally before the practical links appear.

### 5. Bonus Song

Treat the bonus song as an after-credits stinger rather than part of the main set.
It should feel optional but rewarding.

## Copy Blocks

### Intro Timer

- Short on-screen text: Starting soon
- Optional line: Buffering the room while people join

### Animated Logo Video

- Purpose: establish the event identity
- Optional line: DJ Unicorn Tears live stream begins now

### Warning Card / Video

- Purpose: protect the audience and set expectations
- Suggested text: Contains flashing lights, bass-heavy audio, and rapid motion

### Intro DJ UT Music Video

- Purpose: immediate creative hook
- Suggested text: Opening feature from DJ Unicorn Tears

### Feature Video

- Purpose: special event moment
- Suggested text: Remix / special presentation

### DJ UT Random Video

- Purpose: reset attention and add surprise
- Suggested text: Random visual interlude

### Dedication Plaque

- Purpose: emotional close or acknowledgement
- Suggested text: Dedicated to the viewers, supporters, and collaborators

### Outro Credits and Links

- Purpose: practical handoff
- Suggested text: Follow, replay, support, and share links

### Bonus Song

- Purpose: final stinger
- Suggested text: Bonus track for anyone staying through the end

## Notes for Future Versions

If you want to refine this later, the biggest upgrade would be to assign exact time blocks for each segment and create a second template for:

- a tighter 90-minute stream
- a heavier music-first stream
- a more software/demo-first stream
