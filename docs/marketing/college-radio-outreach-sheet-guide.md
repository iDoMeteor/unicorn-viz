# College Radio Outreach Sheet Guide

Owner: Studio Marketing
Status: active
Last updated: 2026-06-09

## Purpose

Use this guide with the outreach CSV template to keep station prospecting and follow-up consistent across the pre-premiere runway.

## Files

- Template CSV: [college-radio-outreach-sheet-template.csv](college-radio-outreach-sheet-template.csv)
- Mission plan: [college-radio-outreach-plan.md](college-radio-outreach-plan.md)

## Setup

1. Import the CSV into Google Sheets.
2. Freeze row 1.
3. Add filters to every column.
4. Sort by `priority_tier` then `state`.
5. Keep one row per station only.

## Status Values

Use these values in `first_outreach_status`, `follow_up_1_status`, and `follow_up_2_status`:

- `not_started`
- `sent`
- `replied`
- `passed`
- `needs_more_info`
- `played`
- `scheduled_interview`

## Cadence

- T-30 to T-15: fill contacts and submission paths.
- T-14: send first outreach wave to tier A and tier B.
- T-11 to T-10: follow up tier A non-responders.
- T-7 to T-6: follow up tier B and start tier C.
- T-3 to T-1: only warm follow-ups and reminder links.

## Minimum Required Before First Send

Each station row must have:

- `station_call_sign`
- `station_name`
- `school`
- `submission_url` or `contact_url`
- one usable email field

## Tracking Rules

- Log every outbound send date.
- Do not send more than 2 follow-ups before premiere.
- Mark `premiere_invite_sent`, `song_link_sent`, and `viz_preview_link_sent` as `yes` only when actually sent.
- Keep notes short and factual.

## Suggested Weekly Goal

- Add 40 to 75 stations/week while researching.
- Verify at least 20 station contact paths/week.
- Keep tier A list under 50 stations for focused outreach.
