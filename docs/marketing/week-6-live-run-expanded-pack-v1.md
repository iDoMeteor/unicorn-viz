## Posting Window Suggestions (Starter)

- Live start / main segment: immediately on go-live.
- Midstream support clip: after first peak moment.
- Recap window: within 2 to 6 hours after stream end.

## QA Before Publishing Each Asset

- First 2 seconds are visually strong.
- One CTA only.
- Links are tested.
- Caption first line is platform-specific.
- Backup asset is ready.
