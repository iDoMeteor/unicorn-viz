# Pre-Launch 7-Day Prep Sprint

Owner: Studio Marketing
Status: active
Last updated: 2026-06-09

## Purpose

This sprint is a short execution bridge before the formal 30-day campaign begins.
It keeps momentum high while software and songs are still finishing.

## Time Budget

- Target: 60 to 90 minutes per day
- Rule: finish the listed output before adding optional tasks

## Day 1: Narrative Lock

## Focus

Define the emotional story spine for the 30-day campaign.

## Tasks

- Write the grand narrative in one page.
- Split it into two arcs: Days 1 to 15 and Days 16 to 30.
- Define 3 emotional targets for each arc.
- Map each arc to core content moments (clip, stream beat, teaser, reveal).

## Output

- One approved narrative brief in docs/marketing or notes workspace.

## Day 2: Stream Skeletons

## Focus

Create low-stress stream structures before live pressure starts.

## Tasks

- Draft run-of-show for Livestream Day 1.
- Draft run-of-show for Livestream Day 2.
- Include for each stream: opening hook, 3 segments, conversion beat, closing CTA.
- Add one backup filler segment per stream.

## Output

- Two stream outlines ready for rehearsal.

## Day 3: Content Bank Batch 1

## Focus

Generate the first wave of ready-to-post assets.

## Tasks

- Produce 4 short clips from existing software/song progress.
- Write 4 caption variants tied to current narrative arc.
- Create 2 reusable thumbnail templates.

## Output

- Publishing pack 1 (4 clips, 4 captions, 2 thumbnail templates).

## Day 4: Content Bank Batch 2

## Focus

Expand content inventory with different angles.

## Tasks

- Produce 4 additional clips with different angles (process, reveal, personality, performance).
- Write 4 additional caption variants.
- Create 2 CTA variants.
- Create 2 additional reusable thumbnail templates.

## Output

- Publishing pack 2 (4 clips, 4 captions, 2 CTA variants, 2 thumbnail templates).

## Day 5: Affiliate Pilot Prep

## Focus

Get referral operations ready before attention spikes.

## Tasks

- Select initial 10 to 20 affiliate candidates.
- Write outreach script.
- Write one-page onboarding guide.
- Define payout/tracking workflow (attribution checks, net-30 process, PayPal handling).

## Output

- Affiliate pilot starter kit.

## Day 6: Dashboard and Tracking QA

## Focus

Stand up a launch scoreboard that can guide decisions fast.

## Tasks

- Create tracking sheets and dashboard.
- Add core metrics: reach, views, watch time, clicks, free/paid/subscription conversions, affiliate-attributed conversions.
- Run one mock week of entries to validate formulas and chart behavior.

## Output

- Working measurement board with tested formulas.

## Day 7: Rehearsal and Publish Calendar Lock

## Focus

Finish with an execution-ready week 1 plan.

## Tasks

- Time-box a rehearsal of first stream opening and transitions.
- Finalize week 1 publishing calendar (day, time, platform, asset, CTA).
- Mark missing assets and assign catch-up blocks.

## Output

- Week 1 execution sheet locked.

## Completion Criteria

The prep sprint is complete when all are true:

- Narrative brief is approved.
- Two stream run-of-show docs are done.
- At least 8 ready clips and 8 captions are prepared.
- Affiliate pilot starter kit is ready.
- Dashboard is live and formula-validated.
- Week 1 calendar is locked.
